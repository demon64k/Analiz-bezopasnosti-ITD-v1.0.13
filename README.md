## 10. ПОШАГОВАЯ ИНСТРУКЦИЯ ПО ЗАЩИТЕ

###  Настройка безопасности для Android 13+

#### Шаг 1: Ограничение разрешений при установке

1. Установите приложение **ИТД** из Google Play
2. При первом запуске **НЕ нажимайте** "Разрешить всё"
3. Для каждого запроса выбирайте:

| Разрешение | Рекомендуемая настройка |
| :--- | :--- |
| **Камера** | "Разрешить только при использовании" |
| **Микрофон** | "Разрешить только при использовании" |
| **Фото и видео** | "Разрешить доступ к выбранным элементам" |
| **Уведомления** | "Запретить" (или "Разрешить" если нужны) |

---

#### Шаг 2: Ручная настройка в системных настройках

1. Откройте **Настройки** → **Приложения** → **ИТД**
2. Перейдите в раздел **Разрешения**
3. Последовательно проверьте:

**🔴 Запретить:**
- ❌ `Файлы и мультимедиа` → `Все файлы` (READ_EXTERNAL_STORAGE)

**🟡 Ограничить:**
- ⚠️ `Камера` → `Разрешить только при использовании`
- ⚠️ `Микрофон` → `Разрешить только при использовании`
- ⚠️ `Фото и видео` → `Разрешить доступ к выбранным элементам`

**🟢 Можно оставить:**
- ✅ `Интернет` (необходимо для работы)
- ✅ `Сеть` (проверка подключения)

---

#### Шаг 3: Сброс рекламного идентификатора

1. **Настройки** → **Конфиденциальность** → **Реклама**
2. Нажмите **Удалить идентификатор рекламы** (или **Сбросить**)
3. Включите опцию **Отключить персонализацию рекламы** (если доступна)

**Результат:** ironSource не сможет отслеживать вас между приложениями

---

#### Шаг 4: Установка брандмауэра (опционально, для продвинутых)

**Рекомендуемые приложения:**
- **NetGuard** (без root) — блокировка доступа в интернет для конкретных приложений
- **AFWall+** (требует root) — продвинутый фаервол

**Настройка NetGuard:**
1. Установите NetGuard из Google Play или F-Droid
2. Найдите в списке **ИТД** (com.itd.app)
3. Заблокируйте доступ к:
   -  `ironsource.com`
   -  `supersonicads.com`
   - ✅ Разрешите `итд.com` (для работы приложения)

---

#### Шаг 5: Использование VPN (рекомендуется)

**Цель:** Скрыть реальный IP-адрес от Cloudflare и ironSource

**Рекомендуемые VPN:**
- **Mullvad VPN** (платный, максимальная приватность)
- **ProtonVPN** (есть бесплатный тариф)
- **Windscribe** (есть бесплатный тариф)

**Не рекомендуется:**
- ❌ Бесплатные VPN с рекламой (они продают ваши данные)
- ❌ VPN от неизвестных разработчиков

---

#### Шаг 6: Мониторинг активности

**Проверка использования камеры/микрофона:**
1. Android 12+ показывает **зелёную точку** в строке состояния
2. Если точка горит, когда приложение свёрнуто — **это подозрительно**
3. Откройте **Панель управления доступом** (Privacy Dashboard) для детальной статистики

**Проверка передачи данных:**
1. **Настройки** → **Сеть и интернет** → **Передача данных**
2. Найдите **ИТД**
3. Проверьте фоновый трафик (если высокий — приложение передаёт данные в фоне)

---

### 🚨 Экстренные меры (если уже отправили номер телефона)

Если вы **уже отправили** номер в Telegram-бот `@itd_verification_bot`:

1. **Включите двухфакторную аутентификацию (2FA)** на всех важных аккаунтах:
   - Google/Gmail
   - Банковские приложения
   - Социальные сети (VK, Telegram, WhatsApp)

2. **Установите фильтр спама:**
   - Приложения: **Call Blocker**, **Truecaller**, **Kaspersky Who Calls**
   - Включите блокировку неизвестных номеров

3. **Будьте бдительны:**
   - Не переходите по ссылкам из SMS от неизвестных
   - Не сообщайте коды из SMS никому
   - Если звонят "из банка" — кладите трубку и перезванивайте по официальному номеру

4. **Рассмотрите замену номера** (в крайнем случае, если спам станет невыносимым)

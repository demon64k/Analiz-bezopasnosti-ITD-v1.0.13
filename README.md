## 1. Исполнительное резюме (TL;DR)

Мобильное приложение **«ИТД»** (возрастной рейтинг 12+) не содержит признаков классического вредоносного ПО (вирусов, троянов), но демонстрирует **критические нарушения этики, прозрачности и правил Google Play**.

**🚨 КРИТИЧЕСКИЕ НАХОДКИ:**
1. **ЛОЖЬ В GOOGLE PLAY:** В разделе "Безопасность данных" разработчик заявляет: **"Данные не передаются третьим сторонам"**. При этом статический анализ выявил SDK **ironSource**, который автоматически передаёт данные множеству рекламных партнёров.
2. **ФИКТИВНАЯ ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ:** Документ внутри приложения полностью идентичен веб-версии и не описывает сбор данных, специфичных для мобильной платформы (камера, микрофон, AD_ID, трекеры).
3. **ТЕХНИЧЕСКАЯ НЕБРЕЖНОСТЬ:** Поддержка Android 8.0 (2017 г.) без внедрения условной логики для современных разрешений (`READ_MEDIA_*`), что создаёт риск запроса устаревшего `READ_EXTERNAL_STORAGE`.
4. **НИЗКАЯ ПРОЗРАЧНОСТЬ:** Использование личного Gmail (`nowkie.com@gmail.com`) для поддержки вместо корпоративной почты.

**Вывод:** Приложение демонстрирует **осознанный обман пользователей**. КАТЕГОРИЧЕСКИ НЕ РЕКОМЕНДУЕТСЯ к использованию.

## 2. Количественная оценка рисков (CVSS v3.1)

Для объективной оценки угроз приватности и конфигурационных ошибок использована адаптированная методика **CVSS v3.1** (Common Vulnerability Scoring System).

**Вектор уязвимости:** `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:M/I:H/A:N`  
**Базовая оценка:** **7.2 (High / Высокий риск)**

### Расшифровка метрик:
| Метрика | Значение | Обоснование |
| :--- | :---: | :--- |
| **AV (Attack Vector)** | **N** (Network) | Данные передаются удалённо через интернет сторонним трекерам (ironSource) и инфраструктуре Cloudflare. |
| **AC (Attack Complexity)** | **L** (Low) | Эксплуатация не требует сложных условий. Достаточно установить приложение и согласиться с запросами. |
| **PR (Privileges Required)** | **N** (None) | Трекеру не нужны предварительные права — приложение само запрашивает их у пользователя при установке. |
| **UI (User Interaction)** | **R** (Required) | Требуется действие пользователя: установка приложения и нажатие «Разрешить» или отправка номера в бот. |
| **S (Scope)** | **C** (Changed) | Уязвимость затрагивает не только приложение, но и ресурсы пользователя (файловую систему) и сторонние сервисы. |
| **C (Confidentiality)** | **M** (Medium) | Раскрытие метаданных устройства, поведенческих данных и потенциальный доступ к медиафайлам. |
| **I (Integrity)** | **H** (High) | **ЛОЖНАЯ ДЕКЛАРАЦИЯ** в официальных документах подрывает доверие ко всей системе безопасности и целостности процесса информированного согласия. |
| **A (Availability)** | **N** (None) | Приложение не вызывает сбоев в работе устройства или потери доступа к нему. |

## 8. Риски поддержки устаревшей версии Android 8.0

**Android 8.0 (API 26)** выпущен в августе 2017 года (~9 лет назад) и не получает обновлений безопасности с 2020-2021 годов.

**Проблемы:**
1. **Устаревшие разрешения:** На Android 8.0-9.0 может запрашиваться `READ_EXTERNAL_STORAGE` (доступ ко ВСЕМ файлам), так как современные `READ_MEDIA_*` появились только в Android 13.
2. **Отсутствие патчей:** 40+ известных уязвимостей без исправлений (CVE-2020-0423, CVE-2021-0315 и др.).
3. **Невозможность использовать современные защиты:** Scoped Storage, Runtime Permissions v2, One-time permissions.

**Вывод:** Поддержка Android 8.0 — бизнес-решение для охвата аудитории, но создаёт критические риски без компенсационных мер.

## 9. Аудит сетевой безопасности и инфраструктуры Cloudflare

Приложение использует **Cloudflare** для CDN, DNS и защиты от DDoS.

**✅ Положительные аспекты:**
- HTTPS по умолчанию (TLS 1.3).
- Защита от MITM-атак и базовая защита от ботов.

**⚠️ Отрицательные аспекты:**
- Cloudflare видит ВЕСЬ трафик и сохраняет метаданные (IP-адреса, время запросов, User-Agent, размеры файлов).
- Юрисдикция: США (подпадает под CLOUD Act, позволяющий правоохранительным органам США требовать данные).
- Шифрование данных на сервере (At Rest) не описано в политике конфиденциальности.

**Рекомендация:** НЕ загружать в приложение сканы документов, паспортов или банковских карт.

## 12. Пошаговая инструкция по защите и минимизации рисков

1. **Ограничение разрешений:** При первом запуске НЕ нажимать «Разрешить всё». Камера/Микрофон: "Только при использовании". Фото/видео: "Доступ к выбранным элементам".
2. **Ручная настройка:** Настройки → Приложения → ИТД → Разрешения. **Запретить:** `Файлы и мультимедиа → Все файлы`.
3. **Сброс рекламного ID:** Настройки → Google → Реклама → Удалить ID рекламы. Включить: "Отключить персонализацию рекламы". Повторять каждые 3 месяца.
4. **Использование VPN:** Mullvad VPN, ProtonVPN или Windscribe для скрытия реального IP-адреса от ironSource и Cloudflare.
5. **Мониторинг активности:** Следить за зелёной точкой в строке состояния (Android 12+). Если горит, когда приложение свёрнуто → ПОДОЗРИТЕЛЬНО.
6. **Обновление ОС:** Если устройство на Android 8.0-10, рассмотреть обновление или замену устройства.

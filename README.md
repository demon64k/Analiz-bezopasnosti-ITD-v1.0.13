AV (Attack Vector): N (Network) - Данные передаются через интернет сторонним трекерам (ironSource) и Cloudflare.

AC (Attack Complexity): L (Low) - Достаточно установить приложение и нажать «Разрешить».

PR (Privileges Required): N (None) - Трекеру не нужны права — приложение само запрашивает их.

UI (User Interaction): R (Required) - Требуется установка и согласие пользователя.

S (Scope): C (Changed) - Затрагивает файловую систему, сторонние сервисы, инфраструктуру Cloudflare.

C (Confidentiality): M (Medium) - Раскрытие Device ID, IP, геолокации, поведенческих данных, медиафайлов.

I (Integrity): H (High) - ЛОЖНАЯ ДЕКЛАРАЦИЯ подрывает доверие ко всей системе безопасности.

A (Availability): N (None) - Приложение не вызывает сбоев устройства.

Интерпретация: Оценка 7.8 помещает приложение в категорию HIGH RISK, что требует НЕМЕДЛЕННЫХ ДЕЙСТВИЙ.

### 5.1. ironSource SDK

Производитель: ironSource Ltd. (Unity Technologies)  
Категория: Advertising & Analytics  
Уровень риска: ВЫСОКИЙ

Что собирает:

- IP-адрес
- Модель устройства, ОС, язык

Кому передаёт:

- Facebook Audience Network
- Unity Ads

Как ограничить:
- Настройки → Конфиденциальность → Реклама → Удалить ID рекламы

- Установить брандмауэр (NetGuard, AFWall+)

Категория: Error Tracking  
Уровень риска: НИЗКИЙ

Что собирает: Только технические логи ошибок (stack trace, версия ОС). Не собирает персональные данные.

## 8. Риски поддержки Android 8.0

Android 8.0 (API 26) выпущен в августе 2017 года (~9 лет назад).

### Проблемы:

1. Устаревшие разрешения:
   - На Android 8.0-9.0 может запрашиваться READ_EXTERNAL_STORAGE (доступ ко ВСЕМ файлам)
   - Современные READ_MEDIA_* появились только в Android 13

2. Отсутствие патчей безопасности:
   - 40+ известных уязвимостей без исправлений
   - CVE-2020-0423, CVE-2021-0315, CVE-2021-0419, CVE-2020-0069

3. Невозможность использовать современные защиты:
   - Scoped Storage
   - Runtime Permissions v2
   - One-time permissions
   - Auto-revoke permissions

Вывод: Поддержка Android 8.0 — бизнес-решение для охвата аудитории, но создаёт критические риски без компенсационных мер.

## 9. Сетевая безопасность (Cloudflare)

### ✅ Положительные аспекты:
- HTTPS по умолчанию (TLS 1.3)
- Защита от MITM-атак
- DDoS protection
- Быстрая загрузка через CDN

### ⚠️ Отрицательные аспекты:
- Cloudflare видит ВЕСЬ трафик (метаданные)

- Методы шифрования
- Хранение ключей

Рекомендация: НЕ загружать сканы документов, паспортов, банковских карт.

## 12. Пошаговая инструкция по защите

### Шаг 1: Ограничение разрешений

При первом запуске:
- Камера: "Только при использовании"
- Микрофон: "Только при использовании"
- Фото/видео: "Доступ к выбранным элементам"
- Уведомления: "Запретить" (если не нужны)

### Шаг 2: Ручная настройка

Настройки → Приложения → ИТД → Разрешения

Запретить: Файлы и мультимедиа → Все файлы
Ограничить: Камера, Микрофон → Только при использовании
Оставить: Интернет, Сеть

### Шаг 3: Сброс рекламного ID

Настройки → Google → Реклама → Удалить ID рекламы
Включить: "Отключить персонализацию рекламы"

Повторять каждые 3 месяца.

### Шаг 4: Использование VPN

Рекомендуемые:
- Mullvad VPN (~$5/мес) — максимальная приватность
- ProtonVPN (есть бесплатный тариф)
- Windscribe (10 GB/мес бесплатно)

НЕ использовать: Бесплатные VPN с рекламой.

### Шаг 5: Мониторинг активности

Android 12+:
- Зелёная точка в строке состояния = камера/микрофон используется
- Если горит, когда приложение свёрнуто → ПОДОЗРИТЕЛЬНО

Проверка трафика:
Настройки → Сеть и интернет → Передача данных → ИТД
Фоновый трафик должен быть <10 MB/день

### Шаг 6: Обновление ОС

Если Android 8.0-10:
- Проверить обновления (Настройки → Система → Обновление)
- Если нет → рассмотреть замену устройства или кастомную прошивку (LineageOS)

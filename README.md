## 1. Исполнительное резюме (TL;DR)

Мобильное приложение **«ИТД»** (возрастной рейтинг 12+) не содержит признаков вредоносного ПО, но демонстрирует **критические нарушения этики и правил Google Play**.

**🚨 КРИТИЧЕСКИЕ НАХОДКИ:**
- **ЛОЖЬ В GOOGLE PLAY:** В разделе "Безопасность данных" разработчик заявляет: **"Данные не передаются третьим сторонам"**. При этом статический анализ выявил SDK **ironSource**, который автоматически передаёт данные множеству рекламных партнёров.
- Политика конфиденциальности внутри приложения **полностью идентична** веб-версии и не описывает сбор данных в мобильном приложении.
- На современных версиях Android используются корректные разрешения (`READ_MEDIA_*`), но базовая поддержка Android 8.0 создаёт потенциальный риск запроса устаревшего `READ_EXTERNAL_STORAGE`.
- Использование обычного Gmail для поддержки вместо корпоративной почты.

**Вывод:** Приложение демонстрирует **осознанный обман пользователей** и нарушение правил Google Play. **КАТЕГОРИЧЕСКИ НЕ РЕКОМЕНДУЕТСЯ** к использованию.

## 2. Количественная оценка рисков (CVSS v3.1)

Для объективной оценки угроз приватности и конфигурационных ошибок приложения использована адаптированная методика CVSS v3.1 (Common Vulnerability Scoring System).

**Вектор уязвимости:** `CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:M/I:H/A:N`  
**Базовая оценка:** **7.2 (Высокий уровень риска / High)**

### Расшифровка метрик:
| Метрика | Значение | Обоснование |
| :--- | :---: | :--- |

| **AC (Attack Complexity)** | **L** (Low) | Эксплуатация не требует сложных условий, достаточно установить приложение. |
| **PR (Privileges Required)** | **N** (None) | Трекеру не нужны предварительные права — приложение само запрашивает их. |
| **UI (User Interaction)** | **R** (Required) | Требуется действие пользователя: установка приложения и нажатие «Разрешить». |
| **S (Scope)** | **C** (Changed) | Уязвимость затрагивает не только приложение, но и ресурсы пользователя и сторонние сервисы. |

| **A (Availability)** | **N** (None) | Приложение не вызывает сбоев в работе устройства. |

*Примечание: Оценка 7.2 (High) отражает КРИТИЧЕСКИЕ нарушения: ложную декларацию в Google Play, наличие скрытых трекеров и осознанный обман пользователей.*

### 💎 Ключевая находка: идентичность политик
Политика конфиденциальности, размещённая **внутри самого приложения**, **полностью идентична** веб-версии документа. Это доказывает, что разработчики просто скопировали текст для сайта, не адаптировав его под мобильную платформу.

### 🚨 КРИТИЧЕСКОЕ НАРУШЕНИЕ: Ложная декларация в Google Play

#### 4.1. Ложное заявление о непередаче данных третьим лицам

**Что заявляет разработчик в разделе "Безопасность данных" Google Play:**

❌ **"Данные не передаются третьим сторонам"**

**Реальность, выявленная статическим анализом:**

Приложение содержит SDK **ironSource**, который:
- **Автоматически передаёт данные** множеству рекламных партнёров:
  - Google AdMob
  - Facebook Audience Network
  - Unity Ads
  - AppLovin
  - И другим рекламным сетям
- **Собирает и передаёт:**
  - Device ID (Android ID, GAID)
  - IP-адрес
  - Модель устройства, ОС, язык
  - Приблизительную геолокацию (по IP)
  - Поведенческие данные (время сессии, клики, просмотры)

**Это является:**
1. 🔴 **ПРЯМОЙ ЛОЖЬЮ** в официальной декларации Google Play
2. 🔴 **НАРУШЕНИЕМ правил Google Play Developer Program Policies** (раздел 4.3: Misrepresentation — Введение в заблуждение)
3. 🔴 **ОСНОВАНИЕМ ДЛЯ НЕМЕДЛЕННОГО УДАЛЕНИЯ** приложения из Google Play
4. 🔴 **ОСОЗНАННЫМ ОБМАНОМ пользователей**, которые полагаются на эту информацию при принятии решения об установке

#### 4.2. Что разработчик признаёт (частично)

✅ **Собирает:** Личная информация, Фото и видео, Аудио  
✅ **Данные шифруются при передаче**  
✅ **Можно удалить аккаунт**

**НО:** Частичное признание сбора данных **не отменяет ложь** об их передаче третьим лицам.

### 4.3. Несоответствие правилу Google Play "Prominent Disclosure"

Google требует, чтобы политика точно описывала практики сбора данных именно в мобильном приложении. **Что НЕ описано:**
- ❌ Доступ к камере (`CAMERA`) и микрофону (`RECORD_AUDIO`).
- ❌ Доступ к хранилищу (`READ_MEDIA_IMAGES`, `READ_MEDIA_VIDEO`).
- ❌ Использование рекламного идентификатора (`AD_ID`).
- ❌ Использование сторонних SDK (ironSource, Sentry).
- ❌ Показ уведомлений (`POST_NOTIFICATIONS`) и аналитика установок.

### 4.4. Неполное описание передачи данных третьим лицам

В политике упомянуты только платёжные партнёры и операторы фискальных данных. **Не упомянуты:** 
- ironSource (рекламная сеть)
- Cloudflare (через который проходит весь трафик)

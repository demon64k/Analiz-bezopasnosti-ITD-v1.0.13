## 1. Исполнительное резюме (TL;DR)

Мобильное приложение **«ИТД»** не содержит признаков вредоносного ПО и прошло базовую проверку Google Play. Однако уровень прозрачности разработки оценивается как низкий. 

Основные замечания: политика конфиденциальности не содержит специфичных для мобильного приложения разделов, присутствуют устаревшие запросы на доступ к хранилищу, а использование обычного Gmail для поддержки (вместо корпоративной почты) указывает на неформальный статус проекта. Приложение пригодно для использования при условии ручного контроля выдаваемых разрешений.

## 4. Анализ политики конфиденциальности

Ссылка, предоставленная разработчиком в Google Play, ведёт на политику, ориентированную преимущественно на веб-сервис. 

**Выявленные недостатки:**
1. **Отсутствие описания мобильных функций**: В документе не упомянуты специфичные для Android разрешения (камера, микрофон, доступ к хранилищу), которые запрашивает приложение.
2. **Неполное описание трекеров**: Использование рекламной сети ironSource и инструмента Sentry не отражено в разделе о передаче данных третьим лицам.
3. **Соответствие правилам Google Play**: Формально наличие ссылки удовлетворяет требованию стора, но её содержание не соответствует правилу "Prominent Disclosure" (Явное раскрытие информации), которое требует чётко описывать сбор данных именно в мобильном приложении. Это распространённая практика среди небольших или начинающих команд разработчиков.

## 5. Анализ встроенных трекеров и разрешений

В коде приложения обнаружено 15 запрашиваемых разрешений и 2 сторонних трекера.

### ️ Встроенные трекеры
| Название трекера | Тип | Уровень риска | Назначение |
| :--- | :--- | :---: | :--- |
| **Sentry** | Crash Reporting | 🟢 Низкий | Стандартный инструмент для отладки и фиксации сбоев. Не собирает персональные данные для рекламы. |
| **ironSource** | Analytics & Ads |  Средний | Рекламная сеть. Собирает обезличенные поведенческие данные для показа таргетированной рекламы. |

### ⚠️ Разрешения, требующие внимания
1. **READ_EXTERNAL_STORAGE** (Чтение содержимого общего хранилища): Устаревший запрос. В современных версиях Android рекомендуется использовать `READ_MEDIA_VISUAL_USER_SELECTED` (доступ только к выбранным файлам). Наличие старого запроса может означать попытку получить доступ ко всей файловой системе на старых версиях ОС.
2. **CAMERA** и **RECORD_AUDIO**: Стандартные запросы для социальной сети, но требуют контроля со стороны пользователя (разрешать только при использовании).

### ✅ Стандартные разрешения (Низкий риск)
`INTERNET`, `ACCESS_NETWORK_STATE`, `WAKE_LOCK`, `CHECK_LICENSE`, `RECEIVE`, `BIND_GET_INSTALL_REFERRER_SERVICE`, `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`, `POST_NOTIFICATIONS`, `AD_ID`.

## 6. Опциональные риски

### Telegram-боты
В процессе использования может упоминаться взаимодействие с Telegram-ботами (например, `@itd_verification_bot`). 

**Оценка риска:**
- Поскольку это не является принудительным требованием для базовой установки и запуска приложения, прямой угрозы нет.
- **Однако**, если пользователь *самостоятельно решит* отправить свой номер телефона в сторонний бот, он должен осознавать риски: отсутствие шифрования, возможное накопление базы данных и риск её утечки. Рекомендуется избегать передачи персональных данных в непроверенные сторонние мессенджер-боты.

## 7. Рекомендации по безопасному использованию

Для минимизации потенциальных рисков при использовании приложения рекомендуется:

1. **Контролируйте разрешения**: При первом запуске отказывайте в доступе ко "Всем файлам". Если система позволяет, выберите опцию «Разрешить доступ только к выбранным элементам» (READ_MEDIA_VISUAL_USER_SELECTED).
2. **Разрешения камеры и микрофона**: Установите в настройках Android значение «Спрашивать каждый раз» или «Только при использовании приложения».
3. **Ограничьте рекламу**: В настройках Android (`Конфиденциальность` → `Реклама`) рекомендуется сбросить или удалить рекламный идентификатор (AD_ID), чтобы усложнить профилирование через ironSource.
4. **Избегайте сторонних ботов**: Не отправляйте свой номер телефона или другие персональные данные в Telegram-боты, упомянутые в приложении, если в этом нет абсолютной необходимости.
5. **Проверяйте обновления**: Следите за обновлениями приложения — разработчик может улучшить политику конфиденциальности и убрать устаревшие разрешения в будущих версиях.
